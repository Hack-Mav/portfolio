# Design Tokens

The portfolio uses a single set of design tokens for colors, typography, spacing,
radius, shadows, and motion. These values are defined in `src/design-system/tokens.ts`
and are exposed as CSS custom properties in `src/styles/tokens.css`.

## Usage

Use the Tailwind theme classes (e.g. `bg-primary-600`, `text-gray-700`) or the
primitive components. The values are all driven by the CSS custom properties,
so they can be updated in one place.
